# Mini Veshrown
Mini Veshrown is a endless wave fantasy roguelike set in the world of Pomehgza.

[Download](https://cyberwolfgames.itch.io/mini-veshrown)

# Features 
* 4 Enemies and 1 Boss
* 8 Weapons
* 4 Playable races
* 1 Pet
* 4 Magic types
* Great music by me (Cy)
* Secrets to an upcoming game I'm working on
  
With much more
